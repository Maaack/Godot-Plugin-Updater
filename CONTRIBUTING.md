# Contributing to Godot Plugin Updater

Thanks for your interest in contributing to Godot Plugin Updater!

## Guide
Steps to contributing:
1. Fork the repository.
2. Create a branch.
3. Fix a bug/add a feature.
4. Review, clean up, and reduce changes to a minimum.
5. Submit a pull request to `Maaack/Godot-Plugin-Updater:main`.
6. Respond to comments and requests from review.

## Issues
If any of these instructions are incorrect, unclear, or out-of-date, feel free to ~~submit a pull request to change them~~ open an issue at: https://github.com/Maaack/Godot-Plugin-Updater/issues .
